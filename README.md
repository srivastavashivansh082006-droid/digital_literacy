This repository contains my **Digital Literacy Portfolio Project** created for **CSE0001 – Digital Literacy** at **VIT Bhopal University**. The project is designed to develop practical digital skills required for academic, professional, and safe online participation.

It includes five tasks based on the course modules:

- Student Digital Portfolio
- Coding & Collaboration Platforms
- Professional Email & Social Media Etiquette
- Cybercrime Awareness Case Study & Prevention Guide

This project helped me understand how to use digital tools responsibly, communicate professionally online, and maintain a safe and effective digital presence.
